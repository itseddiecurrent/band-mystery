# 《乐队酒局杀人事件》

一款单人 3D 浏览器推理游戏。你扮演乐队的调音师，在一场演出后的庆功宴上卷入一桩命案。



## 3D 场景与角色对话

- 使用 Three.js 搭建和渲染房屋的 3D 场景。玩家可以在房间之间移动、调查物件，并与遇到的角色交谈。
- 玩家主动与角色交谈时，在 3D 场景上弹出对话界面，显示该角色的脸部照片和台词。对话使用下方对应的角色图片，结束时收起界面，回到场景探索。

## 待补充

- **人物关系**：谁参加了庆功宴？谁和谁有过节？
- **房屋布局**：玩家在哪里醒来？哪些房间可以搜查？门为什么锁了？
- **案情与时间线**：死者是谁？玩家睡着前后，各人分别在哪里、做了什么？
- **证据**：每条线索在哪里找到？它能支持或推翻哪一种说法？
- **结局**：玩家需要解释哪些事实？不同推断会导向什么结果？

## 单 HTML 交付

最终交付一个可离线双击打开的 `index.html`。开发时保留 `assets/` 中的原图，打包时将对话使用的角色照片转为 Base64 Data URL，直接写进 HTML，例如 `<img src="data:image/png;base64,…" alt="Kat">`。把 Three.js 与游戏 JavaScript 合并打包并内联，CSS 和场景用到的模型、贴图等资源也嵌入同一个 HTML 文件。

四张 PNG 原图合计约 6.6 MiB，Base64 编码会增加约三分之一的体积。打包时可按游戏中的显示尺寸缩放照片，必要时转为保留透明度的 WebP，再嵌入 HTML。验收时把成品复制到一个空文件夹，断网打开，确认 3D 场景能正常加载、发起对话时能弹出对应的角色照片，并且游戏能从开场玩到结局。
