# 剧情画布

独立的本地创作工具，使用黑色网格与从左到右的树状连线。文档包含原有主线的 27 个只读节点，以及已实现的汽水选择与两个分支节点；不自动把构思写进游戏。

汽水选择从庆功宴处分叉。绿色的拿罐分支目前暂停于小莉回应；绿色的冰箱分支接回灰色原主线。车辆结局仍未接入。

## 启动

在仓库根目录运行（Node.js 24，无需安装依赖）：

```sh
node scripts/story-editor.mjs
```

打开 <http://127.0.0.1:8788/>。按 `Ctrl+C` 停止。端口可通过 `STORY_EDITOR_PORT` 设置；与 8787 的统计看板独立。

## 节点颜色

| 颜色 | 含义 | 可操作范围 |
| --- | --- | --- |
| 灰色 | 原有剧情，只读 | 查看、折叠，并添加新后续或分支；不能改写、移动、删除原有内容和连接 |
| 黄色 | 新增，尚未实现 | 编辑标题、条件、笔记与连接；添加、移动或删除 |
| 绿色 | 新增，已实现 | 在详情面板将新增节点的状态改为“已实现”；仍可编辑 |

“已实现”是人工维护的进度标记，不会自动修改游戏或核对代码。导入与服务端保存同样保护灰色节点，不能通过改状态绕过只读限制。

## 编辑

- **选择节点**：单击选中，双击打开详情。原有剧情可查看笔记。
- **子节点**：在选中节点后添加新剧情；已有后续时，新增并行路线。
- **同级**：添加与选中节点并列、共用上级的节点。故事起点没有同级。
- **添加分支**：原有剧情保留原连接并新增备选路线；可编辑节点按需要插入选择节点或新增选择项。
- **调整结构**：在详情中更改上级，或调整同级顺序。不能形成循环，也不能移动灰色节点。
- **删除**：确认后删除选中节点及其后续，可以撤销；不能删除包含灰色剧情的子树。
- **撤销／重做**：支持按钮，以及画布上的 `Ctrl/⌘ Z` 与 `Ctrl/⌘ Shift Z`。刷新后重新开始本次撤销记录。
- **导航**：拖动空白处或滚轮平移；底部缩放；`Ctrl/⌘ + 滚轮` 缩放；“定位”回到选中节点，“全览”显示整棵树。大纲支持搜索和跳转。
- **键盘**：画布获得焦点时，`Tab` 添加子节点，`Enter` 添加同级，左右方向键前往上级／第一个后续。表单内保留正常输入行为。

## 保存与备份

修改自动保存到 [story-tree.json](story-tree.json)，也可点击“保存”或按 `Ctrl/⌘ S`。浏览器保留未保存草稿；保存成功后清除草稿。读写失败时请导出 JSON，避免丢失尚未写入文件的内容。

“导出 JSON”下载整个剧情树。“导入 JSON”在确认后替换当前文档，支持撤销；导入文件必须保留原有灰色节点的内容与连接。文件上限 2 MB，最多 2,000 个节点。

两个窗口同时编辑时，保存会校验文件版本：旧窗口不能覆盖新版本。出现冲突后，点击保存状态或“保存”，先导出当前草稿，再载入最新文件，人工合并需要保留的内容。

编辑器只在本机监听，不读取数据库或凭据。剧情文档、创作页面与服务脚本均独立于游戏；当前 GitHub Pages 发布流程不包含此工具。
