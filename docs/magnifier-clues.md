# 放大镜调查

以下七项线索首次发现时必须开启放大镜，在画面对应位置检查；普通点击和未使用工具的收集动作不会登记线索。

| 线索 | 搜索位置 |
| --- | --- |
| 碎酒杯 | 楼上走廊的地面 |
| 亚瑟的左手 | 楼梯下亚瑟手边；回访同样需要放大镜 |
| 小莉的饮料 | 后门右侧窗台；原有证词和剧情条件仍需满足 |
| 小柔手里的水果刀 | 玉米地，小柔持刀的手 |
| 小柔手腕的伤 | 玉米地，小柔的手腕 |
| 小柔少了一只鞋 | 玉米地，小柔的脚 |
| 威利的领带夹 | 当晚演出合照，威利胸前；找到后继续比对对白 |

## 操作

- 点击工具栏的“放大镜 / Magnifier”。
- 鼠标移动或触屏移动，在放大的圆形镜片里寻找细节；镜片中心对准可检查的位置时会亮起，并出现通用提示。
- 点击该位置进行检查；部分线索仍需读完对应对白才记入线索册。
- 键盘开启工具后，焦点进入搜索画面。方向键移动镜片，Enter / 空格检查，Esc 退出工具。
- 这七个位置不再拥有可直接点击或通过 Tab 枚举的普通热点按钮。
- 其他交互仍可正常点击，也可用镜片检查；屏蔽器的原有隐藏交互保留。

已找到的线索仍可从线索册正常阅读。旧存档不移除已有线索，回退到发现前则需重新使用放大镜。工具位置和开关属于界面状态，不写入剧情存档；实际发现继续使用原有线索 ID。
