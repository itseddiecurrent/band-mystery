# 《乐队酒局杀人事件》

一款单人 3D 浏览器推理游戏。你扮演乐队的调音师，在一场演出后的庆功宴上卷入一桩命案。
## 3D 场景与角色对话

- 使用 Three.js 搭建和渲染房屋的 3D 场景。玩家可以在房间之间移动、调查物件，并与遇到的角色交谈。
- 玩家主动与角色交谈时，对话框显示角色立绘和台词。按 Enter 或点击对话框推进对话和回放。调查与举证通过点击完成，已记录的线索可随时回看。

## 剧本

[场景.txt](场景.txt) 已写到尾声，包含场景顺序、角色台词、调查热点、线索获取条件、两次案情还原和指认流程。玩家从楼上醒来，调查楼梯、隔间、后院和玉米地，随后通过医院证词、警方报告和照片复查案情。

## 单 HTML 交付

最终交付一个可离线双击打开的 `index.html`。开发时保留 `assets/` 中的原图，打包时将立绘和证据图转为 Base64 Data URL 嵌入 HTML。把 Three.js 与游戏 JavaScript 合并打包并内联，CSS 和场景用到的模型、贴图等资源也嵌入同一个 HTML 文件。

目前七张 PNG 原图合计约 11 MiB，Base64 编码会增加约三分之一的体积。打包时可按显示尺寸缩放图片，必要时转为保留透明度的 WebP，证据图需保留放大调查时可辨认的细节。验收时把成品复制到空文件夹并断网打开，确认 3D 场景、角色对话、证据图和从开场到结局的流程均可正常使用。
